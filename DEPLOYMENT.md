## 📦 Как развернуть

### Способ 1: Загрузить архив на хостинг

1. **Соберите проект** (если еще не собрали):

    ```bash
    npm install
    npm run build
    ```

2. **Архивируйте папку `dist`**:
    - Скопируйте все файлы из папки `dist/`
    - Создайте архив (ZIP)

3. **На хостинге**:
    - Загрузите файлы из архива в нужную папку
    - Откройте `index.html` в браузере
    - **Готово! Всё работает!** ✨

### Способ 2: Если хостинг имеет панель управления (cPanel, Plesk)

1. Собрать проект: `npm run build`
2. Загрузить файлы из папки `dist/` через FTP или файловый менеджер
3. Сделать `index.html` главной страницей

### Способ 3: Если хостинг поддерживает Node.js

```bash
npm install
npm run build
```

Загрузить папку `dist/` на хостинг и настроить веб-сервер для раздачи статических файлов.

## 🔍 Проверка работы локально

Перед загрузкой на хостинг можете протестировать локально:

```bash
# Способ 1: Python
cd dist
python -m http.server 8000
# Откройте http://localhost:8000

# Способ 2: Node.js (если установлен)
npx serve dist
# Откройте http://localhost:3000

# Способ 3: Vite preview
npm run preview
# Откройте http://localhost:4173
```

## 🚨 Если что-то не работает

### Ошибка "Файлы не найдены"

- Убедитесь, что загрузили **все** файлы из папки `dist/`
- Проверьте, что структура папок совпадает

### Белая страница / Ошибки в консоли

- Откройте DevTools (F12) → Console
- Проверьте пути в ошибках
- Убедитесь, что все файлы загружены

### Стили не применяются

- Проверьте, что файлы CSS загружены (в DevTools → Network)
- Убедитесь, что путь к `assets/` правильный
